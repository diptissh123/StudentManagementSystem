# Student Management System

## 📌 Project Overview

The Student Management System is a console-based Java application designed to manage student academic records efficiently. It allows users to add, view, search, update, and delete student information and calculate subject-wise total and average marks.

## ✨ Features

- Add student details, including ID, name, and age
- Store marks for different subjects
- Calculate total and average marks
- Display student records
- Search students by ID or name
- Update student information
- Delete student records
- Calculate the class average
- Save and load records using file handling, if implemented

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Collections Framework
- Java Scanner for console input
- File Handling, if implemented

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project in Eclipse or another Java IDE.
3. Ensure the JDK is installed and configured.
4. Run the `Main.java` file.
5. Follow the console menu to manage student records.
